## Projetos

### [ELT Lab](https://github.com/flrodrigues21/elt)

Laboratório de engenharia e governança de dados criado para estruturar ingestão, transformação, armazenamento e gestão de metadados em um ambiente local reproduzível.

- **Problema:** integrar fontes heterogêneas e organizar pipelines auditáveis sem depender de configuração manual para cada fluxo.
- **Solução:** framework ELT orientado por metadados, orquestrado pelo Airflow e executado em uma stack Docker com PostgreSQL, MinIO e OpenMetadata.
- **Capacidades implementadas:** DAGs geradas por configuração; camadas Bronze, Silver e Gold; conectores para bancos, APIs, arquivos e object storage; histórico de execução; catálogo, glossário, ownership, lineage e testes de qualidade; ambiente Jupyter com notebooks de dados.
- **Stack:** Python, SQL, Apache Airflow, PostgreSQL, MinIO, Docker, OpenMetadata, JupyterLab e PySpark.
- **Competências demonstradas:** arquitetura de dados, engenharia de pipelines, modelagem dimensional, governança, qualidade, segurança e documentação técnica.
- **Links:** [documentação técnica](https://github.com/flrodrigues21/elt#readme) · [código](https://github.com/flrodrigues21/elt)

### [Power BI + OpenCode Accelerator](https://github.com/flrodrigues21/Opencode_PBI_Accelerator)

Acelerador independente e não oficial para apoiar o desenvolvimento local de projetos Power BI com IA, mantendo o trabalho versionável nos formatos PBIP, PBIR e TMDL.

- **Problema:** reduzir o esforço de preparar um fluxo local, repetível e validável para autoria de relatórios e modelos semânticos com assistência de IA.
- **Solução:** instalador e scripts PowerShell que integram OpenCode, skills especializadas, CLIs locais e regras de validação para projetos Power BI.
- **Capacidades implementadas:** preparação de projetos PBIP/PBIR; apoio à autoria e ao design de relatórios; análise de modelos semânticos, DAX e TMDL; Best Practice Analyzer; validação, reload e captura pelo Power BI Desktop; dependências versionadas e instalação local.
- **Stack:** Power BI, PBIP/PBIR, DAX, TMDL, OpenCode, PowerShell, Node.js e CLIs da Microsoft.
- **Competências demonstradas:** automação de BI, modelagem semântica, boas práticas de DAX, qualidade, experiência de desenvolvimento e integração responsável de IA.
- **Links:** [documentação e atribuições](https://github.com/flrodrigues21/Opencode_PBI_Accelerator#readme) · [código](https://github.com/flrodrigues21/Opencode_PBI_Accelerator)
